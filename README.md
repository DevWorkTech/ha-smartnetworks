# Умные Сети для Home Assistant

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://hacs.xyz)
![GitHub release](https://img.shields.io/github/v/release/DevWorkTech/ha-smartnetworks)
[![Telegram](https://img.shields.io/badge/Telegram-Channel-blue?logo=telegram&logoColor=white)](https://t.me/DevWorkTech)

Неофициальная интеграция Home Assistant для личного кабинета интернет-провайдера **Умные Сети** — [stat.umnyeseti.ru](https://stat.umnyeseti.ru/).

## Установка

### Через HACS

> **✔️ Рекомендуемый способ**

1. Установите HACS ([официальная инструкция](https://www.hacs.xyz/docs/use/download/download/)).
2. Найдите `Умные Сети` или `Smart Networks` в интеграциях HACS.
3. Установите последнюю версию компонента.
4. Перезапустите Home Assistant.

[![Открыть Home Assistant для добавления репозитория HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=DevWorkTech&repository=ha-smartnetworks&category=integration)

### Вручную

> **⚠️ Не рекомендуется**

1. Скачайте [последний релиз](https://github.com/DevWorkTech/ha-smartnetworks/releases).
2. Распакуйте `umnyeseti.zip` в:

   ```text
   /config/custom_components/umnyeseti
   ```

3. Перезапустите Home Assistant.

## Настройка

1. Откройте **Настройки → Устройства и службы → Интеграции**.
2. Нажмите **Добавить интеграцию**.
3. Найдите **Умные Сети**.
4. Введите **лицевой счёт** и пароль от [stat.umnyeseti.ru](https://stat.umnyeseti.ru/).
5. Завершите настройку.

По умолчанию:

- проверка SSL-сертификата **отключена**;
- обновление данных выполняется каждые **30 минут**.

Эти параметры можно изменить в настройках интеграции.

[![Открыть Home Assistant для добавления и настройки](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=umnyeseti)

## Что умеет интеграция

- показывает лицевой счёт, баланс, абонента и адрес;
- показывает IP, MAC и VLAN;
- отображает тариф, скорость, стоимость и период списаний;
- показывает дату окончания оплаченного периода и количество оставшихся дней;
- рассчитывает сумму, которой не хватает для продления тарифа;
- показывает историю платежей;
- поддерживает несколько лицевых счетов;
- сохраняет последние успешные данные при временной ошибке связи;
- отправляет уведомления о необходимости оплаты;
- позволяет перейти к оплате прямо из Home Assistant;
- сохраняет RAW-данные запросов и ответов для диагностики.

## Оплата

В карточках интеграции доступна ссылка **«💳 Оплатить»**.

Она открывает простую страницу в стиле Home Assistant, где можно:

- проверить лицевой счёт;
- проверить имя абонента;
- изменить сумму платежа;
- перейти к оплате через **СБП / банковскую карту**.

После проверки данных интеграция получает защищённую ссылку платёжного шлюза и автоматически открывает её.

## Уведомления

Если средств на балансе недостаточно для продления тарифа, интеграция отправляет напоминания:

- за **5 дней**;
- за **3 дня**;
- за **1 день**;
- в день окончания — **0 дней**;
- в первые **3 дня после окончания** — `-1`, `-2`, `-3`.

Уведомления отправляются только с **07:00 до 22:00** по времени Home Assistant.

Если средств уже достаточно, предупреждение не отправляется, а ранее созданное уведомление удаляется.

После успешного перехода на платёжный шлюз текущее уведомление также скрывается. Если оплата не завершена и позже наступает следующий контрольный день, напоминание может появиться снова — только если средств по-прежнему недостаточно.

Уведомления отображаются:

- на телефонах через Home Assistant Companion App;
- в панели уведомлений Home Assistant.

## Платежи

Сенсор **«Платежи»** показывает последние операции по счёту в удобном виде: дата слева, сумма справа, а отдельно отображается последний платёж.

## Диагностика

RAW-данные запросов и ответов сохраняются автоматически.

Для скачивания диагностики откройте:

**Настройки → Устройства и службы → Умные Сети → ⋮ → Скачать диагностические данные**

В диагностике доступны последние запросы и ответы API, включая этап оплаты. Пароли, cookies, CSRF-токены и другие чувствительные значения маскируются.

При ошибке интеграция сохраняет последние успешно полученные данные и показывает информацию о проблеме в Home Assistant.
